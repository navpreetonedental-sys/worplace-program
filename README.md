Krest One Workplace Dental Program
Overview
This project contains the landing page for the Krest One Workplace Dental Program, designed to help businesses provide employees with convenient access to dental care across the Krest One Dental network.
Key Features
- Responsive desktop, tablet, and mobile layout
- Krest One brand colours: Navy #0D2D4D and Gold #BB9232
- Workplace Dental Program benefit sections
- Interactive clinic location map
- Search by clinic, city, or address
- Multiple Ontario clinic locations
- Contact Form 7 integration for WordPress
- Calls-to-action for employers and organizations
Files
- krest-workplace-program.html — Main landing page
- README.md — Project documentation
WordPress / Contact Form 7
Replace the sample shortcode with the shortcode generated by your WordPress installation:
[contact-form-7 id="YOUR-FORM-ID" title="Workplace Dental Program"]
Recommended fields: Company Name, Contact Name, Job Title, Business Email, Phone Number, Number of Employees, Primary Office Location, and Area of Interest.
Map
The clinic map uses Leaflet with OpenStreetMap tiles. Internet access is required for map tiles and external map assets to load. Clinic data can be updated as locations are added, removed, or changed.
Deployment
1. Upload the landing-page assets to the website.
2. Add the HTML/CSS/JavaScript to the appropriate WordPress page or template.
3. Add the correct Contact Form 7 shortcode.
4. Confirm Leaflet and OpenStreetMap resources are permitted by the website's Content Security Policy.
5. Test desktop, tablet, and mobile layouts.
6. Test clinic markers, search, CTA buttons, and form submissions before launch.
Brand Guidelines
- Krest One Navy: #0D2D4D
- Krest One Gold: #BB9232
Use navy for primary headings, high-contrast sections, and core brand elements. Use gold selectively for accents, icons, highlights, and key calls-to-action.
